## Purpose

This slice turns the recovered UNDERSTAND contracts into executable runtime scaffolding without inventing missing River or position-timer rules.

## Implemented now

- Five-movement phase order:
  HOLD → RELATE → UNDERSTAND → BECOME → RETURN
- Turn transition from RETURN to the next turn's HOLD
- Thirty-turn ceiling in the core state contract
- Seven public River positions as structural slots
- Interaction trace fields sufficient to test Assistance-report eligibility
- Explicit COMMIT / DENY / HALT outcomes
- Append-only transition audit entries
- Explicit source-gap guards for:
  - exact nine-card-type position-timer table
  - exact final seven-slot River distribution schedule
- Six-turn Starting Arc structural qualification scaffold
- Replay-equivalence assertion for that scaffold

## Not implemented and not inferred

The following remain SOURCE RECOVERY GAP:

1. The complete authored position-timer values for all nine card types.
2. The final authored deterministic distribution schedule for the seven River slots.

The runtime therefore refuses to execute these behaviors. It returns HALT with a source-gap code rather than choosing a temporary value, random order, or inferred sequence.

## Assistance-report rule represented

A card is report-eligible only when:
- the player legally interacted with it; and
- that interaction made a change.

Timer-only disappearance without such a changed legal interaction remains excluded at the structural contract level.

## Qualification meaning

The six-turn fixture is not a six-turn gameplay PASS.

It is an executable structural scaffold proving:
- movement order is deterministic;
- six turns can advance reproducibly;
- missing source-dependent behaviors halt explicitly;
- the same fixture serializes identically on replay.

Full Starting Arc qualification remains HELD until the source gaps required by its actual card flow are recovered.

## Change gate

Future SCE runtime changes should preserve:
- source-first configuration;
- no RNG for authored deterministic rules;
- no partial mutation on DENY/HALT;
- stable audit output;
- replay equality;
- explicit update of tests when source-backed behavior changes.
